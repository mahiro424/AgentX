# Triage 标签

## 类别角色

| 角色及标签 | 含义 |
| --- | --- |
| bug | 已有行为损坏 |
| enhancement | 新功能或改进 |
| design-input | UI 设计输入与验收 |

## 状态角色

| 角色及标签 | 含义 |
| --- | --- |
| needs-triage | 待评估 |
| needs-info | 待补充信息 |
| ready-for-agent | 需求、依赖和必要输入齐全，可交给 Agent |
| ready-for-human | 待人工处理 |
| wontfix | 明确不处理 |

每个已分拣任务恰好有一个类别角色和一个状态角色。
