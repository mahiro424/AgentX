## 3. 关键实现接缝

### 会话组织和正文检索

- 扩展现有产品任务元数据，组织修订与执行观测分离；改名、置顶、归档、查看和索引不刷新最近活动时间。活动/未决任务在 Main 禁止归档；恢复不执行。
- 搜索浮层复用既有侧栏和焦点原语。产品按公开历史/可见执行项建立 `cache/search.sqlite`，保存最小可重建投影和覆盖信息，不使用私有引擎数据库。
- 字面子串、中文、英文忽略大小写及标点有确定测试；不承诺语义搜索或依赖默认 FTS 自动支持中文。参数化查询；一个会话合并为一个结果。
- 命中保留 task/thread/turn/item，打开后重新核验源历史；缺失/过期不假称定位成功。只投影可见消息与允许的工具文本，不索引隐藏推理、凭据、附件全文或全电脑文件。

### 非项目任务和材料

- 草稿仍不创建引擎会话；第一次有效提交才分配任务。非项目工作目录位于 `.AgentX/workspaces/<taskId>`，不是伪造一个项目，也不是临时缓存。
- 现有 Task/Draft/Execution/Lease 接缝一起支持可空项目关联；不破坏 M1 项目、意图及轮次绑定。产品 SQLite 迁移先一致性备份，失败不清库。
- 文件选择由 Main 原生对话框处理；拖放文件经 Preload 的 Electron 原生路径接口提取后走同一 Main 校验，不暴露通用文件系统接口。材料按真实路径/身份去重，失败与更改就地可见；移除不删原件，目录引用不全量上传。
- 普通办公附件不是原生协议中的通用上传类型。按固定版本公开输入及本地工具接缝传递可核验的材料引用/读取内容，必须验证真实模型使用路径；不将单纯路径字符串冒称已经读取。
- 材料是结构化对象，随现有草稿 CAS 修订保存；提交意图记录实际使用的材料版本。选择成功、可读取、实际已读和模型确实使用是不同证据，不在输入框里用隐藏字符串承载关联。外部文件变化必须重新核验，读失败不返回空内容；草稿和历史引用不能互相覆盖。
- 保留单一加号入口、Enter 发送/补充、Ctrl+Enter 换行、IME 保护和同一发送/停止按钮。图片可选择/预览，但在图像输入兼容未验证时明确阻断含图发送，不静默丢弃，不调用其他模型。

### 办公与预览

- 不建设产品侧规划循环。Codex 仍是唯一执行者；产品提供本地解析/生成工具与材料/结果接口。库和公开扩展方式在实施前用 Context7/官方源码核验版本、许可、打包与边界，未通过不宣称可用。
- 新增依赖仅为本切片必要的文档解析/生成能力，不换 Electron/React/Forge 或数据库。耗时/不可信文件解析在受管理的独立进程执行，受大小、数量、超时与任务归属约束，不能卡住 Main。
- 读取与生成均用真实文件，保留原件哈希及当前用户修改；输出新版本，同名冲突不静默覆盖。复杂宏、复杂格式无损往返、完整 Office 编辑器不在范围内。
- 对合成文档/表格重新解析，核对段落、表头、行数、数值和公式。不能把模型一句“已完成”、扩展名或未重算的公式缓存当正确结果。文本型 PDF 有页码与提取失败；扫描/OCR 未开放不假称识别成功。
- 右侧标签按需打开，真实路径与关联轮次可查；文档只读阅读/版本/缩放，表格工作表/滚动/值与公式，PDF/图片页码/缩放；不提供假的编辑按钮。预览内容无脚本或产品 Preload 权限。缺失、锁定、损坏、格式不支持均可定位原文件。
- M2-02 先接通有限材料/文件预览接口与文本标签；表格、文档逐切片扩展，不新建通用资源框架。标签以任务、材料或结果来源、轮次/版本共同定位，不仅按文件路径去重；旧响应不得覆盖新版本，文件变化使旧预览失效，但不自动启动续改。
- 每个切片现场验收都从真实控件添加合成材料开始，经 Flash 实际读取/生成、独立解析结果、打开右侧预览，再在原 thread 继续一轮；完成后重开核验材料关联与已结束历史。图像能力未验证时只验证本地预览与发送阻断，不调用其他模型。

### 恢复与人工收尾

- 扩展现有 `getReconciliation`、精确进程身份和 lease，不按名字批量杀进程，不把根 PID 消失等同于后台退出。
- 先验证可持续追踪的所属进程与完整回收证据，再提供释放动作；发现旧记录没有足够归属证据时保留未决，不能用用户点击覆盖事实缺口。必须交付新任务在真实崩溃/重开后的可恢复链路，而不是永远禁用收尾按钮。
- 读取到匹配的权威终态且无残留时恢复该终态。历史不可恢复但证实无残留时，展示已知文件变化/缺失和核对依据，由用户明确知悉后以 `unconfirmed` 收尾，不伪造成功或 turn。
- 原 thread 可用才能显式开始新轮；不可用则显式新建，旧记录保留。任何步骤失败保留草稿/意图与诊断，不自动重发任务、审批或外部动作。

## 5. 风险与完成边界

关键风险为：大历史索引不阻塞界面与遗漏提示；附件路径链接/变化与原件保护；文档解析器的 Windows 分发、公式与损坏文件处理；旧版未决任务的残留证明。风险不能通过静默降级、缩减格式、永久禁用必要恢复能力或放宽权限解决。若必须改变黑盒边界/上游补丁/既定产品范围，停止相关改动，另行取得授权。

M2 不包含浏览器/电脑自动操作、其他模型或提供商、插件市场、通用备份恢复、安装器/签名/自动更新和公开发布；这些 V1 或后续事项保留。M2 完成不关闭完整 V1 父 PRD #1。
