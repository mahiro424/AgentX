## 问题陈述

用户希望用自然语言说明最终目标，让 AI 读取自己的本地项目或办公材料，连续执行跨文件、跨工具和跨软件的工作，而不是只返回建议。现有碎片化方式要求用户自己搬运上下文、执行命令、整理产物，也难以区分“AI 说完成了”和“实际结果已验证”。

用户需要始终知道当前授权范围、正在做什么、实际改动和产物在哪里，以及哪里失败或仍需人工处理；在检查后可以继续调整。首版面向 Windows 个人用户，不以编程知识、官网账户或自建数据库为前置条件。

## 解决方案

AgentX 是本地优先的通用桌面 AI 工作台。用户选项目或添加材料、说明目标，由 Codex App Server 理解、规划并调用可用工具执行；产品负责组织、授权呈现、过程和结果检查。首版模型服务为 DeepSeek，使用用户自己的 API Key。

### SCOPE-V01 首版范围

| 分类 | 首版内容 | 完成边界 |
| --- | --- | --- |
| 桌面入口 | Windows 安装应用、本地档案、设置 | 日常使用不要求手工命令行；没有官网登录 |
| 项目与任务 | 目录关联、独立任务、历史、标题、置顶、搜索、归档 | 组织与执行分开，不因切换页面中止任务 |
| 连贯执行 | 目标、澄清、实际计划、工具过程、补充、中断 | 不伪造进度，执行结束不等于目标已满足 |
| 代码 | 读项目、多文件修改、命令、测试、差异 | 真实文件和测试结果；保护已有修改 |
| 办公 | TXT/Markdown/DOCX、CSV/XLSX、文本型 PDF | 默认保留原件、输出可打开的新版本 |
| 视觉与电脑 | 支持图像的模型加实际桌面工具 | 真实观察、操作、验证、停止；未通过不算完整首版 |
| 浏览器与跨软件 | 网页读取、结构化操作、信息流转 | 操作来自工具，不假设模型服务执行电脑动作 |
| 结果检查 | 文件、差异、预览、验证和未完成事项 | 实际证据优先；无通用自动回滚承诺 |
| 工具与技能 | 已配置来源、启停、健康、基础管理 | 不先建商城，不盲装未审计依赖 |
| 数据与恢复 | 本地元数据、独立引擎目录、备份、诊断 | 凭据不入普通日志；恢复不重放副作用 |

“帮我批准”是验证后开放项；不可用时明确禁用，不阻止其他模式交付。图像驱动电脑操作则是完整首版的真实场景门禁，不能用该能力不可用却称完整交付。

同一产品可保存多个任务。首版顶层用户任务串行执行，其他任务仍可浏览与编辑草稿；不自动排队启动，避免共享文件和桌面控制冲突。此限制不重建或替换引擎内部调度。

本地优先不等于离线：模型调用会按任务发送必要文字、代码或截图；本地选中文件不等于已上传。浏览器、软件和第三方服务的授权独立，不自动扫描上传全电脑。

## 用户故事

端：windows-desktop。以下均为用户可观察行为。

- US-1：作为首次使用者，我想直接建立本地档案并进入应用，以便无需注册或 OpenAI 账户开始准备工作。
- US-2：作为用户，我想直接填写或替换 DeepSeek Key、临时查看明文、拉取并多选模型、逐模型测试及启停连接，以便决定哪些模型可供工作台选择。
- US-3：作为用户，我想关联已有项目或普通文件夹，以便围绕现有内容开展工作。
- US-4：作为用户，我想创建不绑定项目的任务并添加文件、图片和文件夹，以便处理临时材料。
- US-5：作为用户，我想在侧栏重命名、置顶和归档会话，并按标题或正文搜索、定位和恢复历史，以便组织持续工作。
- US-6：作为用户，我想查看任务历史并继续原任务，以便不用重复搬运上下文。
- US-7：作为用户，我想说明目标并只回答重要澄清问题，以便把普通步骤交给 Agent。
- US-8：作为用户，我想看到实际回复、计划和工具执行过程，以便理解进展而非猜测。
- US-9：作为用户，我想在执行中补充要求并看到是否已接收，以便及时纠正方向。
- US-10：作为用户，我想在默认模式下批准或拒绝需要额外权限的操作，以便控制授权范围。
- US-11：作为用户，我想在已验证可用时选择“帮我批准”，以便减少适合自动审查的打断。
- US-12：作为用户，我想显式选择完全访问并看清实际边界，以便自主决定更广的文件与网络授权。
- US-13：作为用户，我想让 Agent 阅读代码、多文件修改并运行验证，以便得到可检查的实现。
- US-14：作为用户，我想整理和生成文本文档及 Word 文档，以便获得可打开的新版本。
- US-15：作为用户，我想清洗、合并、统计和处理表格公式，以便得到正确的表格结果。
- US-16：作为用户，我想读取 PDF 和图像材料并知道格式限制，以便不会把识别失败误当成功。
- US-17：作为用户，我想让 Agent 读取网页并执行已授权的页面操作，以便减少重复浏览与录入。
- US-18：作为用户，我想让 Agent 在可用环境中观察并操作软件界面，同时可以停止，以便完成没有合适接口的工作。
- US-19：作为用户，我想把网页、本地表格和文档串联成一项任务，以便交付连续工作的最终结果。
- US-20：作为用户，我想检查文件变化、产物和验证记录，以便确认实际交付。
- US-21：作为用户，我想直接检查本轮结果并继续提出修改，以便由我决定是否满足目标，而不必填写验收状态。
- US-22：作为用户，我想中断当前执行并保留已发生的结果，以便及时止住不合意的工作。
- US-23：作为用户，我想切换页面、最小化或收至托盘而不中断任务，以便同时处理其他事情。
- US-24：作为用户，我想在断线或重启后恢复记录并核对实际状态，以便避免重复执行有副作用的动作。
- US-25：作为用户，我想管理技能、工具、来源与授权并查看可用性，以便理解能力来自哪里。
- US-26：作为用户，我想管理本地数据、清理缓存和按清单备份，以便保护原件与敏感数据。
- US-27：作为用户，我想看到可定位的错误和组件能力状态，以便知道如何处理失败。
- US-28：作为用户，我想看到服务商实际提供的用量，以便了解消耗且不被虚假零值误导。
- US-29：作为用户，我想选择深浅主题或跟随系统，以便长时间舒适使用。
- US-30：作为用户，我想用键盘操作并在 Windows 缩放下正常阅读，以便不依赖精确鼠标点击。

### 状态策略

| 状态 | 全局处理 | 局部补充 |
| --- | --- | --- |
| 加载 | 保留已显示内容；复用 DESIGN §5 Loading | 首次加载可骨架；不编造执行百分比 |
| 空内容 | 解释缺少什么并提供下一步 | 无历史、无搜索结果、无选中模型分别说明 |
| 错误 | 就地持久展示原因、影响与可用操作，保留草稿 | 预览失败不清空会话；测试失败不丢失模型勾选 |
| 禁用 | 不接受操作并有原因说明 | 未配模型仍能查看历史；未知执行状态不能再提交 |
| 文件添加 | 已选择、读取中、可用、失败 | 本地引用不是上传；移除草稿附件不删除原件 |
| 等待用户 | 用批准或回答图标及文案，不用普通运行转圈替代 | 待处理请求关联具体操作；旧请求失效 |
| 提交与停止中 | 防重复；只有权威事实才能进入执行或停止终态 | 不能将停止应答视为已经停完 |
| 断线或未知 | 保留历史、输入和产物，先核对 | 不自动重放发送、写入或审批 |
| 历史缺失且无残留 | 保留“执行结果未确认”及检查依据 | 用户知悉后可收尾；新工作不伪装继承缺失历史 |
| 本轮结束 | 显示真实终态和已知未完成事项 | 无验收状态、验收按钮或验收数据库实体 |
| 设置变更 | 区分输入中、保存中、已保存、待生效和保存失败 | 涉及引擎的改动不热切当前轮；旧测试不能冒充新配置有效 |
| 主题与窗口变化 | 不改变执行状态；保持焦点与输入 | 窄窗收起面板不是停止；通知点击回到对应会话 |

运行转换统一遵循[状态流转契约](../architecture/AgentX_State_Machines.md)。

##### UI-NAV-INLINE 项目与会话就地操作

项目名显示简称，悬停可见完整目录；折叠箭头只展开或收起。项目标题右侧“…”菜单包含置顶/取消置顶、编辑名称、在资源管理器中打开、归档项目内会话、移除关联。独立铅笔图标是同一个“编辑项目名称”动作的快捷入口，有明确 tooltip 和可访问名称。编辑浮层显示名称输入、只读目录、“保存”“取消”；Enter 保存，Escape 放弃，失败保留输入。改显示名不移动磁盘文件夹。

项目区“+”直接选择目录。规范化目录重复时定位已有项目；缺失目录标识不可用，可从编辑浮层显式重新关联。重新关联不改写已有会话的历史目录；活动会话存在时禁止改变其工作目录。移除关联需确认不删除磁盘文件和历史会话，相关会话保留原目录信息并可由搜索找回。批量归档列出范围，有活动或核对中会话时拒绝并列出原因，不静默部分成功。

会话悬停或聚焦时显示置顶、归档；右键菜单及标题菜单提供重命名和同等动作。置顶项在置顶区显示，不在项目和最近区重复占行；搜索返回的会话仍唯一。项目内会话按最近活动组织；最近区收纳未置顶的非项目会话。活动期间不因每个输出事件抖动排序，当前选中项保持可定位。运行中用转圈，等待用户用专门标记；非运行时显示最近活动时间，悬停显示具体时间及终态。最近活动指创建、用户提交/补充获接收或本轮进入终态的时间，不因打开预览、改名或重建索引改变。归档可撤销；恢复仅恢复列表可见性，不执行任务。

##### UI-SEARCH-CONTENT 会话搜索浮层

搜索图标或 Ctrl+K 打开浮层（这是 AgentX 选择，不宣称是所有 Codex 版本默认键位）。输入框置顶；默认“标题和正文”，可切仅标题/仅正文，按项目筛选并勾选“包含已归档”。空查询展示近期会话，不是独立全部任务页。标题命中优先，再按相关度与活动时间排序；一个会话合并为一条结果，显示标题、项目或“未关联项目”、时间和最多两行命中片段。

正文范围为用户及助手可见消息和可见工具文本，不索引隐藏推理、密钥、浏览器 cookie、附件正文或全电脑文件。结果高亮匹配词，点击正文命中定位到可核对的消息/工具项，标题命中打开会话最近位置。归档命中带标记，可查看或显式恢复；输入问题不暗中恢复归档或启动执行。上下键移动、Enter 打开、Escape 关闭并恢复原焦点。中文、英文大小写与标点行为一致可测，首版支持字面片段匹配，不承诺语义检索。

索引未完整时明确“部分历史尚未可搜索”，显示已覆盖范围及重试，不用“无结果”冒充全量检索完毕。历史源不可读时保留索引结果但标记不可定位，不把过期片段当当前事实；索引应可清除重建，不能成为历史真相源。

- 端 / 运行环境：windows-desktop / Electron。
- page-id：workbench。
- 主任务：说明目标、执行连续工作、查看结果并继续修改。
- 覆盖的用户故事：US-1、US-3 至 US-24、US-27、US-28、US-30。
- 默认态设计稿：windows-desktop-workbench.png，已固化为新会话正常入口；其他状态使用下列规格及补充评审图。
- DESIGN 复用：§5 输入、按钮、列表行、卡片、状态徽章、搜索；§3 等宽文本。
- UI 设计描述：继承 windows-desktop app-shell。新会话主区居中，简短标题“今天想完成什么工作？”，下方一块多行输入与工作位置选择；不绑定项目时显示“未关联项目”。最多四个短示例仅填入草稿，不自动执行。首次建立本地档案不要求昵称，未配置模型时提供“配置模型”入口，返回后保留草稿及材料。
- 变体：提交后同一界面显示会话标题和可检查目录，中央连续呈现消息与实际执行项，底部固定同一个输入组件；模型和权限主要选择入口只在输入区，不在标题区再放一套。只有打开文件、改动或操作内容时才出现右侧工作内容面板。前台正在读历史时不强制滚底，提供新内容提示。另一会话活动时可看历史、写草稿，但禁止启动并提供“查看正在运行的会话”，不排队、不自动抢占。

##### UI-COMPOSER 输入与材料

唯一“+”菜单添加文件、图片和文件夹，支持拖放、粘贴图片。工作目录不是附件；添加目录不复制或上传整个目录。材料只在添加后显示名称、类型、读取状态与移除动作；重复路径去重，读取失败可移除或重试，提交前重查存在性和访问权限。无材料不显示零计数。移除只影响草稿，历史引用不被改写。含图片而所选模型不支持时明确阻断相关提交，不丢弃图片继续执行。

主按钮固定同一位置：空输入为禁用“↑”，可提交为“↑”，提交中防重复，运行中为“■”，停止中禁用并给文字状态。运行时仍能输入；有内容时显示文字动作“补充要求”，快捷键 Enter 也提交补充，主按钮继续保留停止。补充明确区分发送中、已接收、未接收；当前轮已结束时留为草稿，用户决定下一轮，不自动改投。默认 Enter 提交、Ctrl+Enter 换行；运行中 Enter 提交补充而不是停止。中文 IME 组合选字阶段不发送。M1 按此固定行为实现，通用设置中的快捷键切换留待后续。

模型选择器只显示已启用连接下勾选的模型，可搜索；一次选择一个。尚未测试的模型标“未测试”，失败或不兼容项保留说明且不伪装可运行。未选模型时显示“选择模型”。有活动轮时本轮模型与权限只读；设置中的变更另显示待生效。用量在本轮末尾的可展开详情中显示，真实输入/输出、缓存、估算区分，缺失显示未知，不默认铺满速度和耗时指标。

##### UI-RUN-FEEDBACK 过程、审批与继续修改

计划仅由实际引擎事件提供，默认紧凑展开当前步骤；不虚构百分比或必须经过的步骤。工具项以动作、目标、状态和耗时一行概括；参数、命令与输出按需展开。已完成步骤不继续使用“正在”文案。关键失败不只放在折叠区或一闪而过的 Toast。

审批就在对应操作附近说明来源、对象、动作和申请范围，提供“允许一次”“拒绝”；只有协议支持且范围可明确时才提供会话内记住选项。需要回答的问题保留原问题和输入，可用选择及自由文本；与执行审批分开。请求失效后禁用旧按钮。点击允许不代表工具已成功，拒绝不删除先前产物。

本轮结束只给工作摘要、实际文件/改动、验证记录及未完成事项。用户直接输入修改要求；不设验收状态、验收通过按钮或专门验收页面。失败与中断也保留部分结果。点击结果文件在右侧打开或聚焦已有标签，避免重复打开同一对象。运行中可查看中间产物，但明确标“仍在修改”或“尚未验证”，不宣称最终交付。

##### UI-CONTENT-PANELS 文件与工作内容

右侧只列已打开的内容标签，允许关闭、重新打开、调宽和放大；不永久列满所有类型。关闭标签或收起面板不删除文件、不停止执行。文件对象显示实际路径及关联轮次，不能用同名文件混淆版本。

| 内容类型 | 必须提供 | 边界与错误 |
| --- | --- | --- |
| 文件 | 打开、复制路径、资源管理器显示 | 缺失/锁定有明确原因；本地原件不叫“下载” |
| 代码改动 | 文件清单、增删行、比较范围、查看原文 | 区分本轮可归因改动与工作区已有改动；二进制不伪造文本差异 |
| 文档 | 只读阅读、原件/新版本切换、缩放、本机打开 | 不承诺完整 Word 排版或编辑；预览失败仍可定位原文件 |
| 表格 | 只读工作表切换、横纵滚动、单元格值/公式查看、本机打开 | 无新增工作表/直接编辑控件；不把未计算公式缓存当可靠结果 |
| PDF/图片 | 页码、缩放、格式与读取错误 | 扫描识别需实际能力；不以空白冒充识别成功 |

| 电脑画面 | 目标应用、观察时间、控制者、停止/接管 | 旧截图不得标实时；Windows 前台操作不能与用户争抢输入 |

人工接管先停止并确认相关自动动作已结束，再交出输入；未确认期间不显示可安全操作。继续工作由用户明确发起新一轮，重新观察现状，不承诺通用暂停点续跑。锁屏、UAC、窗口失效会显式阻断相关动作。只读网页或文档不能获得产品 Preload 权限。

| M1-05 | partialResult | 失败和中断也能检查已知变化；查看结果不改变执行终态 |

M1-04 首次交付只保证真实执行与控制，M1-05 才交付完整的检查面板与已结束历史恢复。附件、专用澄清表单、可交互终端、办公预览、网页与电脑画面、搜索及用量详情不在这两个切片提前放可用入口。

##### UI-SETTINGS-GENERAL 通用

提供跟随系统/浅色/深色、界面缩放、发送快捷键、关闭窗口到托盘/询问、完成通知（从不/仅后台/总是）、失败和需要处理通知。尊重 OS 通知授权，不能把开启偏好当已获得系统许可。默认仅后台通知完成，失败和等待用户单独提示。主题及缩放即时反馈，不重启执行。可选本地昵称为次要一行，没有登录/密码。全局工作偏好提供受控文本编辑与保存，来源为顶层 AGENTS.md；不出现第二个引擎偏好编辑入口。清空偏好仅修改偏好文本，不重置其他设置。

##### UI-SETTINGS-MODELS 模型连接

首版仅 DeepSeek；服务商地址显示官方预置值，协议和地址属于详情，不提前开放任意第三方连接或承诺所有模型兼容。连接页顶端为 DeepSeek 及“启用”开关，下面是 API Key 输入（默认掩码、右侧眼睛）、保存反馈，再下面“模型”标题和“拉取模型”按钮、候选列表。

直接粘贴替换 Key，不需要先点“更换密钥”。失焦或 Enter 提交一次完整值；点击拉取/测试前先等待该次保存完成，失败不继续请求。不把掩码字符当真实输入、不在每个字符输入时覆盖已保存 Key；清空编辑框不自动删除旧凭据。持久化仍用系统加密，显隐仅用户点击后短暂返回受控设置页，失焦离开窗口或关闭设置后隐藏并清除明文状态。

每行是复选框、模型显示名/精确 ID、最近测试状态和右侧刷新式图标（tooltip“测试连接”）。拉取只更新候选列表，不自动勾选新增项、不清空已有选择；远端不再返回的已选模型保留失效提示。模型 ID 来自实际服务响应；能力元数据来自经验证的公开配置，不靠名称推测视觉/工具能力。多选仅控制工作台可见性；实际执行一次选一个。首版不提供移除服务商按钮，关闭连接保留密钥和勾选，阻止新轮使用。

测试仅对所点模型、当前已保存配置发最小推理请求；显示未测试、测试中、测试成功/失败及时间，详情含脱敏错误和耗时。首次测试处说明可能产生 API 用量，不发送用户文件、历史或截图，不自动批量测试。拉取成功不等于推理成功，推理成功不等于工具/视觉链路兼容。测试结果不篡改勾选。修改 Key 或关键配置后旧测试标过期；进行中的测试回包只能关联原配置版本，不覆盖新配置状态。

启停、勾选和模型变更对新轮生效，活动轮保留原生效快照；若要立即禁用正在使用的连接，提示先停止当前轮。旧默认模型被取消后要求重新选择，不静默换服务或模型。新配置生效失败明确阻止新执行，不自动用旧 Key 冒充新配置成功。

##### UI-SETTINGS-TOOLS 工具与技能

用“工具”“技能”两个页内标签。工具行显示名称、用途、来源、允许使用开关和实际状态；已启用但未授权/连接失败是可表达的组合，不自动翻转用户开关，也不将其列为可执行能力。根据状态给“配置”“授权”“重试”或“查看详情”，避免多个同义修复按钮。详情显示最近检查时间和必要脱敏根因；启动命令、环境变量等仅高级区编辑，不任意下载运行程序。

技能显示名称、用途、来源路径和启用状态，支持查看说明及打开本地位置；用户可选择已存在技能目录，校验后显式引入，不自动扫描其他产品目录。技能是工作方法，不自动赋予工具权限。工具配置和技能改动的生效点明确，活动轮不热换依赖。工具失效不静默退到权限更大的替代工具。

##### UI-SETTINGS-PERMISSIONS 权限与隐私

默认模式为请求批准；帮我批准只有验证通过才可选；完全访问单独确认范围。设置定义新会话默认值，输入框展示本会话生效值，不将二者混为一份“全局已授权”。模式说明用普通语言；技术映射在详情，不要求小白操作多个沙箱开关。

已有浏览器站点与应用授权列表只显示实际授权，允许查看范围及撤销；撤销后不能继续发起新动作，正在发生且无法撤销的动作明确标记。没有授权记录时不制造绿色状态。说明模型请求可能包含必要任务内容，本地保存不等于离线；敏感材料不默认纳入诊断。不得用产品标签替代执行端真实权限。

##### UI-SETTINGS-DATA 数据

主层仅显示数据目录、打开目录、备份/恢复、清理缓存及用量大小；产品与引擎内部目录放详情。备份前给包含/排除清单、目标和一致性要求，活动执行时不进行不一致的引擎快照。备份包含产品设置、会话记录及受管理产物，默认排除凭据、浏览器登录、缓存和外部项目原文件；恢复前预检版本和影响，并保留恢复前快照，不清库掩盖失败。

缓存清理只包含可重建预览、缩略图和可重建搜索索引；清理索引后明确重新建立期间搜索范围不完整。不包含会话真相源、产物、原件、Key、浏览器 profile。展示实际将清理的范围并确认，失败报告已完成与未完成范围。没有笼统“一键清空全部”或无验证目录迁移入口。

##### UI-SETTINGS-DIAGNOSTICS 关于与诊断

默认显示产品版本和简短健康摘要，按组件错误给原因、影响和对应修复入口；展开后展示引擎/工具版本、协议和脱敏诊断。用户主动导出到选定本地位置，先给内容预览，不自动上传。不存在产品账户额度或无归属“本轮用量”。

更新为经过验证的产品与引擎组合，首版只提供手动选择已验证版本的流程，不建设自动更新服务、不单独追随上游 latest。活动执行时不更换引擎。诊断和更新结果失败保持可见，不把“检查版本”当升级成功。

## 实现决策

### IMPL-RUNTIME-BOUNDARY

产品组织任务、呈现权限和结果；引擎负责规划、上下文、模型调用和工具执行循环。公开适配模块隔离协议变化，不把产品业务写入 Codex。默认零补丁。

### IMPL-LOCAL-IDENTITY

本地档案、模型认证、工具服务授权是三个独立概念。首版不要求 OpenAI 账户或官网身份；DeepSeek Key 由用户管理，产品不内置共享凭据或自有扣费。

### IMPL-STATE-OWNERSHIP

任务归档与执行投影分离；结果检查是用户行为，不设独立验收实体或状态。终态由引擎事实确定；未知状态不能通过超时猜测。具体转换和竞态由状态流转文档统一维护。

### IMPL-PERMISSION-ENFORCEMENT

请求批准为默认；自动审查仅在验证后开放；完全访问由用户显式选择。真实权限必须在执行端实现，不靠界面标签或提示词。外部工具权限与引擎沙箱独立核验。

### IMPL-RESULT-INTEGRITY

结合引擎文件项、工具产物和实际文件变化形成检查清单；保留已有改动，不能把所有变化归因于 Agent。办公原件默认保留，覆盖与回退均需明确范围与现状检查。

### IMPL-RECOVERY-NO-REPLAY

发送、中断、审批结果不确定时保存未决状态，恢复只读核对；确认无残留执行且用户明确继续后才发起新执行。历史无法恢复时保留未确认标记，不伪造成功；原会话不可用则由用户新建任务。不能重放可能有副作用的操作来“确保成功”。

### IMPL-DATA-ISOLATION

产品元数据、引擎历史、凭据与用户原件分开；不依赖私有引擎数据库。独立运行目录不等于屏蔽所有项目和共享配置，必须检查来源与生效值。

### IMPL-SEARCH-PROJECTION

产品通过公开历史读取和执行事件建立最小可重建文本搜索投影，关联 task/thread/turn/item；索引不用于恢复执行或重新构造模型上下文。不直接读引擎私有数据库，不为全文检索修改 Codex。

### IMPL-MODEL-SELECTION

连接启用、模型被勾选、推理测试与 Agent 能力兼容分别维护。配置保存版与本轮生效版分离，Key/配置变化使测试过期；当前轮不热切。用户主动显隐 Key 是受控设置页的临时例外，不改变持久化和日志禁明文要求。

### IMPL-UPSTREAM-COMPATIBILITY

引擎、生成协议和工具版本形成固定兼容基线。升级前验证，活动执行时不热替换；回滚考虑数据迁移，不只是切换可执行文件。

### IMPL-M1-DESKTOP-DATA

保持 Electron + React + TypeScript、Forge + Webpack。Main 是产品写入者，使用内置 node:sqlite 管产品元数据、版本化配置存普通偏好、Electron safeStorage 系统加密存 Key；不加 ORM、数据库服务或新框架。正式默认根为用户主目录下 `.AgentX`，测试始终独立临时根。打包后的 SQLite 读写和合成凭据加解密在 M1-01 验证，真实设置保存由 M1-02 交付；环境不支持时阻断，不用开发 Node 的成功代替，也不改成明文。

### IMPL-M1-PUBLIC-SEAMS

在现有 getAppInfo 有限桥上按需增加设置与模型、项目与会话、执行与结果三组产品接口。Renderer 只操作产品 DTO；Main 校验输入、来源、任务归属与当前状态。操作含产品任务 ID 和操作 ID；请求/事件携带已知的 thread/turn/item 关联，未知不能捏造。没有原始 RPC、通用文件系统或任意 shell API 暴露给 Renderer。

产品持有项目、会话组织、草稿、发送意图、引擎关联和结果引用；完整执行历史归引擎，文件内容归实际文件。M1 顶层任务串行，不自动排队或重发。补充、停止与审批都经过同一实际执行协调边界，不能仅改变界面状态。

### IMPL-M1-PINNED-ENGINE

固定官方 Codex 0.153.4、既有校验值和对应生成协议，补丁数为零，作为应用资源管理而非随机读取 PATH。只允许 Flash 和请求批准；原生 workspace-write / on-request 生效值必须实际核验，其他权限模式不开放。

复用 G1 已测配置和关联方法，不搬入自动拒绝审批、固定任务文本或测试报告编排。M1 历史读取先使用已实测的 thread/read(includeTurns:true) 公开路径并隔离在适配模块；它不等于跨进程恢复已通过，失败不得当作空历史。共享技能来源记录保留，独立 CODEX_HOME 不被描述成完全隔离。turn/completed 才确定终态；应答丢失、断线或异常退出先核对，不自动重复执行或响应审批。

按三项页面规格（一个壳层、两个功能主界面）的默认与变体状态验收，覆盖 960×640、1280×820、深浅主题、Windows 100%/125%/150% 缩放、键盘及输入法。记录产品与引擎版本，不把测试界面截图当成预先设计稿。

### TEST-M1-DESKTOP-BASE

### TEST-M1-MODEL-SETTINGS

### TEST-M1-PROJECT-SESSIONS

通过产品目录关联/读取接口和真实侧栏验证选择取消、中文与空格目录、规范化去重、显示名编辑、失效目录和存储失败；不复制、不移动、不删除项目。自动测试由公共产品接缝建立合成记录，生产页面不塞假会话；真实会话由 M1-04 执行后产生，并回归活动标记与时间。

### TEST-M1-EXECUTION-CONTROL

通过产品提交/补充/停止/审批接口与固定版本 stdio 适配边界验证关联、防重复、串行占用、正文/工具流、当前轮模型快照、允许/拒绝和旧请求失效。逐行为注入应答丢失、旧终态、断线；不能只断言按钮颜色。人工验收在合成项目核对真实副作用；停止应答不是终态，补充失败不改投新轮。

### TEST-M1-RESULT-HISTORY

从公开产品结果/历史读取接口检查真实文本变化、shell 产生的修改、原有人工 WIP、缺失/二进制结果和命令输出/退出码。独立重跑验证命令，不只信模型说明。固定公开历史读取路径连接已结束任务，测试重开与同线程续轮、旧事件归属；接口报错不能返回空列表伪装成功。

### TEST-M1-LIFECYCLE

通过真实窗口/托盘、有限执行快照与拥有的进程验证：切页、最小化和隐藏不重建任务；活动退出可取消，确认后等待真实停止和回收。故障注入后只读核对未决意图、进程与历史，副作用次数不增加；不能按进程名清理其他应用。自动测试不用真实 Key/用户目录，强制系统变更另行批准。
