## 已核验选型

保留 ExcelJS 4.4.0。DOCX 读取采用 mammoth 1.12.2 的公开 `extractRawText({ buffer })`，不渲染其 HTML、不开放外部文件读取；生成采用 docx 9.7.1 的 `Document` / `Paragraph` / `Packer.toBuffer`。许可原文继续随锁定生产依赖打包。

PDF 采用 pdfjs-dist 6.3.289：有界解析进程提取文字，Chromium 绘制页面。经 Context7 与该版本发布物核对，Node 下限修正为 22.13（CI 22.22.3 不变）；项目级 `omit=optional` 不安装可选 native canvas，锁文件仍如实记录其依赖关系。资源仅复制所用 ESM/worker、CMap、字体及浏览器解码资源，附原始许可；不复制整个 npm 包或 native 模块。实际随包路径见下方记录。不包含 OCR、PDF 生成或专业 Office 编辑。
