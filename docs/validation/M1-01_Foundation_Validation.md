## 1. 输入与实际实现

父 PRD 为 [#1](https://github.com/mahiro424/AgentX/issues/1)，本次按 `UI-M1-SHELL` 的 8 个状态推进。依赖 [PR #12](https://github.com/mahiro424/AgentX/pull/12) 和 [PR #13](https://github.com/mahiro424/AgentX/pull/13) 已合入 `m1`，#6 的真实就绪简报已引用依赖证据。

实现位于 Main、Preload、Renderer 和普通偏好存储模块；仅提供 `getAppInfo/getPreferences/savePreferences` 三个接口。没有模型连接、项目关联或 Agent Runtime 业务；工作台发送保持禁用，草稿仅在当前窗口内保留。

| 项目 | 实测 |
| --- | --- |
| 开发及 CI 构建 Node | 22.22.3 |
| 打包 Electron | 44.2.0，Windows x64 |
| Electron Main 内置 Node | 24.20.0；不是开发 Node 版本 |
| 包入口 | `.webpack/main` |
| 正常数据根 | 用户主目录下 `.AgentX` |
| 自动测试数据 | 本切片验收时位于 `.local-validation/foundation` 下独立随机目录，通过 `AGENTX_DATA_DIR` 注入；M2-02 起默认采用系统临时目录下的 `agentx-desktop-test-*`，截图仍留在仓库忽略目录 |
| 模型请求 | 本切片没有模型调用代码，测试没有调用 DeepSeek |

```powershell
npm ci
npm run typecheck
npm run package
npm test
node tests/desktop/capture.cjs
```

`npm test` 启动 `out/AgentX-win32-x64/AgentX.exe`，不是在普通浏览器加载页面。真实包中只有编译后的应用资源和依赖许可证等必要文件；未打入测试目录、原始 G0/G1、缓存、正式用户数据或引擎下载。

测试环境移除常见凭据变量名（KEY/TOKEN/SECRET/PASSWORD 等）。这是当前不调用模型的测试环境清理，不宣称对任意命名凭据或同一 Windows 用户提供强隔离。临时合成目录保留供故障核对，不上传，不自动删除已有证据；不是备份或数据清理产品功能。

公开测试接缝及完整断言见 [桌面测试](../../tests/desktop/foundation.test.cjs)。加载/故障注入仅在测试启动的 Main 进程内替换受控 IPC 响应，生产代码没有测试开关或假成功路径。

另有三类数据/接口验证：

1. 在打包 Main 使用内置 `node:sqlite` 建立合成探针，验证写入、事务回滚和应用重开读取。
2. 在同一真实环境要求系统加密可用，再以随机合成文本加密、同进程解密及重开后的解密比对；只把密文及摘要写入探针文件，不降级明文。这不是业务数据库或真实 Key 管理完成。
3. 经产品接口拒绝非法偏好；相同页面地址的其他窗口通过实际 IPC 请求仍被拒绝，不更改原配置。Renderer 不获得任意文件、命令或原始 IPC 接口。

## 4. 失败记录与修复边界

- 初次窗口桥接拒绝来自 Forge 的 Windows 文件 URL 形式与 Chromium 规范 URL 不一致；只规范化加载地址，保留 sender、mainFrame、URL 和参数检查。
- Playwright 默认模拟浅色媒体条件，造成 nativeTheme 已变更但测试媒体断言仍为浅色；测试显式采用 `colorScheme: null`，回到真实系统主题。没有使用强制点击掩盖失败。
- 本机组合测试曾在“关闭再重开”用例超时。调试日志显示 UI 调用已结束、调试连接已断开，但 Chromium 进程仍在退出清理，单次观察约 19 秒；重开用例单独调整为 90 秒预算，单个 UI 操作仍限时 5 秒，无自动重试或强制退出成功路径。原失败保留。
- 初次 [Windows CI](https://github.com/mahiro424/AgentX/actions/runs/34144085056) 的侧栏相关 3 项失败。后续日志实际记录首次窗口为 **1024×720**；测试显式设置真实窗口到 1280×820 后，[当前尺寸修正提交的 CI](https://github.com/mahiro424/AgentX/actions/runs/34144455623) **12/12 通过**。未修改产品断点或跳过小窗断言。
- 独立静态审查提出“收起侧栏 ref 变空”的疑点；定位发现同一 ref 会重新绑定展开按钮，并追加实际收起后的 activeElement 断言，实测通过；未据此做不必要的产品改动。

本机 12 项组合测试已通过。后续提交仍以该提交的实时 CI 为准，不将旧运行冒充当前 head 检查。
