# AgentX 核心兼容证据（公开脱敏摘要）

日期：2026-09-07。来源为既有 G0/G1 本地历史报告；本轮只整理发布摘要，没有重跑模型，也没有改写历史结论。完整原件和原始运行目录保留在本地、不随仓库发布。原件指纹、关键计数与边界见[机器摘要](compatibility-evidence.json)。本文不证明 M1 产品已完成。

## EVIDENCE-G0-FIRST

首轮 G0 **失败**：12 项通过、1 项失败、1 项受阻、3 项未执行。严格共享技能来源隔离不满足，实验在会话检查前停止；后台观察到 3 次 CONNECT，均被测试代理拒绝，不能声称零联网。固定引擎、协议生成、握手和部分数据路径通过，不代表全部进程树与 Windows 沙箱已验证。

用户后来明确将共享技能发现作为非阻断来源观察，暂不推进隔离补丁。这个后续决策不把第一次失败改成成功。原 G0 报告的“尚未开始 G1”是当时状态，不再作为当前开发指令。

## EVIDENCE-G1

固定官方 Codex 0.153.4 + deepseek-v4-flash，补丁数 0。引擎 EXE SHA-256 为 `444a3f0008050605cae73cd9b7a2dcac61294062dfaab56dd20430fd6498518b`；版本对应[官方发布](https://github.com/openai/codex/releases/tag/rust-v0.153.4)。

- 后续 G0：16 项通过、2 项受阻观察；共享来源不作为本次核心验证阻断。
- G1：合成代码项目的两个文件实际修改；引擎运行验证命令退出码 0，4 项业务断言通过，客户端独立复跑通过；测试文件与项目指令文件未改。
- 同一活动引擎中的同 thread 续轮通过；执行后 thread/read(includeTurns:true) 读取 3 轮。跨进程恢复尚未验证。
- 文本轮取得 turn/started 后中断，收到应答和 turn/completed(interrupted)。样本没有活动工具，不证明工具/外部软件已经可以可靠停止。
- 工具命令环境未发现模型凭据；不等于完整安全审计。临时关闭插件、自动审查和多 Agent，只作用于验证子进程，没有修改全局配置。

第一次 G1 已完成双文件工作和续轮，但停止因启动时序失败，第三轮结果未知。随后核对直接进程和相关测试路径，保留失败/核对记录，在全新合成项目复测；没有重放旧任务，也没有把第一次失败重写为通过。

## 未验证与当前路线

尚未完成：真实 Electron 产品、打包后的 SQLite/safeStorage、产品审批允许/拒绝、工具运行中停止、跨连接/跨进程恢复、完整进程树回收、办公/浏览器/电脑操作。共享技能严格隔离不满足，G1 也没有全量出站抓包；不能声称完全隔离或零后台联网。
